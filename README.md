Sample Maven project to check different functions of Spring framework

This repository contains various examples demonstrating the use of the Spring Framework. Each package focuses on a different aspect of Spring, such as dependency injection, bean lifecycle, and aspect-oriented programming.

Packages

1. org.useSetter
This package demonstrates dependency injection using setter methods.
Main.java: Initializes the Spring context and retrieves a `Doctor` bean to demonstrate setter-based dependency injection.

2. org.useConstructor
This package demonstrates dependency injection using constructor methods.
main.java: Initializes the Spring context and retrieves a `Books` bean to demonstrate constructor-based dependency injection.

3. org.useAnnotation
This package demonstrates the use of annotations for dependency injection.
main.java: Initializes the Spring context and retrieves a `Mother` bean to demonstrate annotation-based dependency injection.

4. org.scope
This package demonstrates the use of bean scopes in Spring.
main.java: Initializes the Spring context and retrieves `HeadMaster` beans to demonstrate different scopes.

5. org.beanLifeCycle
This package demonstrates the bean lifecycle in Spring.
MAIN.java: Initializes the Spring context and retrieves a `Warden` bean to demonstrate the bean lifecycle.

6. org.aspectOrientedProgramming
This package demonstrates aspect-oriented programming (AOP) in Spring.
Main.java: Initializes the Spring context and retrieves a `ShoppingCart` bean to demonstrate AOP.
